# Compute sample sizes for each iteration

Compute sample sizes for each iteration

## Usage

``` r
.help_gen_sample_size(
  n = NULL,
  size = NULL,
  prob = NULL,
  method = "poisson",
  iterations = 1,
  ...
)
```

## Arguments

- n:

  Fixed sample size

- size:

  Population size

- prob:

  Probability parameter

- method:

  Sampling method

- iterations:

  Number of iterations

- ...:

  Additional arguments for custom methods

## Value

Vector of sample sizes
