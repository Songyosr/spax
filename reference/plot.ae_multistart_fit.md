# Plot saved diagnostics from the selected allocation fit

Plot saved diagnostics from the selected allocation fit

## Usage

``` r
# S3 method for class 'ae_multistart_fit'
plot(x, type = c("fit", "convergence", "state"), ...)
```

## Arguments

- x:

  An allocation multistart fit.

- type:

  Existing selected-fit diagnostic to display.

- ...:

  Arguments forwarded to the selected-fit plot method.

## Value

The selected diagnostic method's result, invisibly.
