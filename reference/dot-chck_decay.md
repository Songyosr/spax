# Validate inputs for decay calculation

Validate inputs for decay calculation

## Usage

``` r
.chck_decay(distance, method, sigma = NULL, snap = FALSE)
```

## Arguments

- distance:

  Numeric vector, matrix, or SpatRaster of distances

- method:

  Character string or function specifying decay method

- sigma:

  Numeric parameter controlling decay rate

- snap:

  Logical for validation skipping
