# Validate inputs for sample_pmf

Validate inputs for sample_pmf

## Usage

``` r
.chck_sample_pmf(x, n, size, prob, method, iterations, evolve_prop, snap)
```

## Arguments

- x:

  SpatRaster input

- n:

  Sample size

- size:

  Population size

- prob:

  Probability parameter

- method:

  Sampling method

- iterations:

  Number of iterations

- evolve_prop:

  Evolution proportion

- snap:

  Logical for snap mode
