# Validate numeric values for likelihood computation

Validate numeric values for likelihood computation

## Usage

``` r
.chck_likelihood_values(x, allow_negative = FALSE, method = "mean")
```

## Arguments

- x:

  Numeric vector to validate

- allow_negative:

  Logical; if TRUE, allow negative values

- method:

  Character string indicating computation method

## Value

Invisible TRUE if valid, error otherwise
