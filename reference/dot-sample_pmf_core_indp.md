# Generate spatial samples

Generate spatial samples

## Usage

``` r
.sample_pmf_core_indp(x, n_samples, iterations, replace_0 = TRUE, snap = FALSE)
```

## Arguments

- x:

  PMF raster

- n_samples:

  Vector of sample sizes

- iterations:

  Number of iterations

- replace_0:

  Logical for NA replacement

- snap:

  Logical for snap mode

## Value

Multi-layer SpatRaster of samples
